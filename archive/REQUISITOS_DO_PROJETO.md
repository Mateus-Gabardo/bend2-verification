Este arquivo reúne as instruções da disciplina para as avaliações e para o trabalho final. Use os itens como checklist durante o desenvolvimento do artigo.

## Trabalho final: artigo

### Tema

- [ ] Submeter o tema até **27/10/2026** pelo [formulário de submissão de tema](https://forms.gle/Tk9ordwudC99gWw9A).
- [ ] Desenvolver um artigo que possa ser submetido a um dos destinos indicados: [SE4FP](https://cbsoft.sbc.org.br/2026/pt/workshops/papers/), JSERD, Erlang Workshop ou outra conferência/periódico.
- [ ] Para consultar artigos relacionados, buscar por SE4FP nos [PDFs do SE4FP 2026](https://cbsoft.sbc.org.br/2026/pt/workshops/papers/) e nos [anais do SE4FP 2025](https://sol.sbc.org.br/index.php/se4fp/issue/archive).

### Implementação funcional

O trabalho deve incluir uma implementação em linguagem funcional ou usar conceitos de linguagens funcionais em outra linguagem. A implementação deve demonstrar, pelo menos:

- [ ] Funções de primeira classe, incluindo uma função passada como parâmetro.
- [ ] Funções nomeadas e anônimas.
- [ ] Casamento de padrões (*pattern matching*).
- [ ] Recursão.
- [ ] Processamento de coleções.
- [ ] Repositório público ou equivalente (Codeberg, GitHub, GitLab ou similar) com o código da implementação.
- [ ] Link do repositório incluído no documento do artigo.

A ementa de referência está no [repositório da disciplina](https://codeberg.org/adolfont/caes005-introduction-to-functional-programming/src/branch/main/README.md).

### Documento e referências

- [ ] Usar o [template do CBSOFT 2026](https://www.overleaf.com/project/69320bdf1918ba90eb56e9f3). Para trabalhar localmente, baixar o ZIP do template no Overleaf.
- [ ] Seguir o formato de *Research papers*: até **5 páginas de artigo**, mais **1 página de referências**. Apêndices podem ter páginas adicionais.
- [ ] Incluir as pessoas autoras nesta ordem: uma ou duas pessoas estudantes; depois, o professor da disciplina; se a pessoa estudante for do PPGCA, incluir também o(s) orientador(es).
- [ ] Incluir no artigo uma nota de rodapé com o link para uma pasta em serviço de nuvem (Proton Drive, Google Drive ou equivalente) contendo os PDFs dos artigos citados.
- [ ] Incluir DOI ou link nas referências sempre que disponível.
- [ ] Inserir no documento o link do repositório da implementação.
